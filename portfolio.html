OpenDART 연결

내 Cloudflare Worker 만드는 법 (무료 · 약 5분)
  1. Cloudflare에 가입하고 로그인합니다.
  2. 왼쪽 메뉴 Workers & Pages → Create → Hello World 템플릿으로 Worker 생성 → 이름(예: dart-proxy) 입력 → Deploy. (메뉴 이름은 Cloudflare 화면 개편에 따라 조금 다를 수 있습니다)
  3. Edit code를 눌러 기존 코드를 모두 지우고 아래 코드를 붙여넣은 뒤 Deploy.
  4. 화면에 표시된 주소(https://dart-proxy.○○○.workers.dev)를 위 Worker 주소 칸에 넣고 연결 테스트.
worker.js
// OpenDART 중계용 Cloudflare Worker
// 브라우저 → (이 Worker) → opendart.fss.or.kr  : 응답에 CORS 헤더를 붙여 돌려준다.
export default {
  async fetch(request) {
    const cors = {
      'Access-Control-Allow-Origin': '*',
      'Access-Control-Allow-Methods': 'GET, OPTIONS',
    };
    if (request.method === 'OPTIONS') return new Response(null, { headers: cors });
    if (request.method !== 'GET') return new Response('Method not allowed', { status: 405, headers: cors });

    const url = new URL(request.url);
    // OpenDART의 /api/*.json, /api/*.xml 만 중계 (아무 사이트나 중계하는 '열린 프록시'가 되지 않도록)
    if (!/^\/api\/[A-Za-z0-9]+\.(json|xml)$/.test(url.pathname)) {
      return new Response('OpenDART relay: use /api/company.json?...', { status: 404, headers: cors });
    }

    const res = await fetch('https://opendart.fss.or.kr' + url.pathname + url.search);
    const headers = new Headers(cors);
    headers.set('Content-Type', res.headers.get('Content-Type') || 'application/octet-stream');
    return new Response(res.body, { status: res.status, headers });
  },
};

이 Worker는 OpenDART의 /api/ 경로만 중계하도록 막아 두었습니다. API 키는 내 Cloudflare 계정의 Worker만 거쳐 DART로 전달됩니다.

OpenDART는 브라우저에서 직접 호출하면 CORS로 차단되어, 외부 무료 프록시를 거칩니다. 내 Cloudflare Worker를 쓰면 키가 내 계정 안에서만 전달되고 안정적입니다. 공용 프록시는 API 키가 포함된 요청이 남의 서버를 통과하고, 수시로 막히거나 가입을 요구합니다. 키가 없다면 OpenDART에서 신청하세요.
